# Nekover2 patches (copied for reference)

These scripts come from https://github.com/Nekover2/OneUI8-Tablet-GSI
They contain hardcoded offsets for one specific Tab S9 Mystic build.
They will abort on any other services.jar / SystemUI.apk.

They are provided here only as documentation of the method.
They do NOT produce a working Redmi 9T image by themselves.
